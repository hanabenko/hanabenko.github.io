There's no better time than spring to start something new.

If you’ve been meaning to learn how to code — or to teach it — this is your sign.

I was a Code in Place instructor in 2025, and it was one of the most meaningful teaching experiences I’ve had.

Applications are open here: **https://codeinplace.stanford.edu/**

## What It Looks Like

Code in Place runs for six weeks, from May through early June. Each week builds on the last:

- **Week 1:** Thinking like a computer scientist  
- **Week 2:** Solving more complex problems in a finite world  
- **Week 3:** Introduction to Python  
- **Week 4:** Control flow and programming with input  
- **Week 5:** Graphics and function calls  
- **Week 6:** Data + calling APIs of large language models (like ChatGPT)

The structure changes slightly each year, but the goal stays the same: make programming approachable and actually doable for beginners.

## Why It’s Different

There are plenty of ways to learn coding online. But Code in Place isn’t just videos and assignments.

You’re placed in a small cohort. You meet live every week. You have an instructor, peers, and an active forum. You’re learning alongside people all over the world — at the same pace.

That community piece makes a huge difference. It keeps you accountable. It makes the hard parts feel manageable.

## Why I Recommend It

As an instructor, I watched students who had never written a line of code start building real programs by week six.

Some shifted their majors. Others started exploring tech careers. The biggest change, though, was confidence.

Sometimes all someone needs is six structured weeks to realize:

> *I can do this.*

## If You’re Hesitating

The biggest concern is usually time.

But it’s six weeks. It runs once a year.

If you’re even considering it, apply. Give it a fair shot.

You might discover a new skill. You might discover a new direction. Or you might just prove to yourself that you’re capable of more than you thought.

Spring is for starting things.

This could be one of them.
